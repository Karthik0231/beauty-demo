# Project Map - beautdemo

## Project purpose
**Maison Aurélia** — Apple Style Reference Midnight Hardware Gallery applied to clinical luxury beauty, facial bodywork, hair architecture, editorial complexion makeup, and private suite booking (`Next.js 15 App Router + TypeScript + Tailwind v4 + GSAP ScrollTrigger + Lenis + Lucide`).

## Structure
- `PRODUCT.md`, `DESIGN.md`, `.impeccable/design.json`, `.impeccable/surfaces/app.page.md` — Pinned Apple Style Reference tokens and surface direction.
- `public/images/` — Bespoke AI-generated dark-obsidian assets (`aurelia-logo.jpg`, `hero-beauty-stage.jpg`, `dark-serum-macro.jpg`, `hair-architecture-dark.jpg`, `barrier-creme-dark.jpg`) + verified photography (`facial-1.jpg`, `facial-4.jpg`, `facial-skin-a.jpg`, `portrait-glow-1.jpg`, `portrait-glow-3.jpg`, `spa-hero.jpg`, `spa-bath-luxury.jpg`, `hair-styling-3.jpg`).
- `src/app/globals.css`, `src/app/layout.tsx`, `src/app/page.tsx` — Exact Apple Style Reference CSS custom properties, `@fontsource/inter` typography roles, Lenis + GSAP ScrollTrigger sync.
- `src/data/salon.ts` — Rituals, highlights, 4-stage clinical protocol, before/after clarity studies, client perspectives, specialists.
- `src/components/` — `Navbar`, `HeroSection`, `HighlightsSection`, `SkincareExperience`, `TreatmentsWorkspace`, `CompareWorkspace`, `PricingResetCard`, `BookingConcierge`, `Footer`, `Modals`, `MagneticButton`.
